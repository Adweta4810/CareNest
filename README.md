# CareNest

CareNest is a family medicine reminder tracker that helps users manage medications for themselves and their family members.  
The app allows users to add medicines, assign them to family members, and receive reminders so no dose is missed.

## Features
- Track medicines for multiple family members
- Set reminders for medicine schedules
- Mark doses as taken or snooze reminders
- View daily summary of taken, pending, and missed medicines
- Simple and organized interface for family health management

## Goal
The goal of CareNest is to make medicine management easier for families by keeping all reminders and health tracking in one place.
